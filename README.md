# Excel-titanic-dashboard

Titanic Excel Dashboard Project

This project demonstrates Excel skills used in data analyst and BI roles.

Skills Used:

* Pivot Tables
* COUNTIFS
* SUMIFS
* IF formulas
* Data cleaning
* Excel Dashboard creation
* Data visualization

Project Overview:

The Titanic dataset was cleaned and analysed in Excel to explore survival patterns.

Analysis performed:

1. Survival by Gender
2. Average Fare by Passenger Class
3. Survival Rate by Embark Location
4. Family Size calculation
5. High Fare classification

Dashboard:

A dashboard was created using Pivot Charts to visualise key insights.

Key Insights:

* Females had a higher survival rate than males
* First class passengers paid higher fares
* Survival varied by embark location
* Family size impacts passenger grouping

This project demonstrates Excel analytical skills for business intelligence and data analysis placements.
